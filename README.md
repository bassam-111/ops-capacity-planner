# Ops Capacity Planner

A small Python + Pandas CLI tool for operations teams. Give it a CSV of
tasks (owner, effort in hours, due date, status) and it spreads each
task's remaining effort evenly across the working days left before its
deadline, then compares each person's daily load against their daily
capacity.

It flags three things an ops lead needs to see before the week starts:

- **Overloaded days** — planned hours above a person's daily capacity
- **At-risk tasks** — not enough working days left to fit the effort
- **Overdue tasks** — due before the planning start date

## How to run

```bash
pip install -r requirements.txt
python3 capacity.py                    # plan from today, data/tasks.csv
python3 capacity.py --start 2026-11-09 --capacity 6
python3 capacity.py --tasks my-tasks.csv --out output/
python3 test_capacity.py               # run the 5 tests
```

## Input

`data/tasks.csv` — one row per task:

```csv
task_id,title,owner,effort_hours,due_date,status,priority
T-101,Weekly client status digest,Bassam,4,2026-11-09,open,high
```

`status` is `open` or `done` (done tasks are excluded from the plan).
Weekends are skipped when spreading effort; only Mon–Fri count.

## Output

- `output/plan.csv` — one row per person per working day
  (`date, owner, hours, capacity, overloaded`)
- `output/report.md` — the plain-text summary below

## Sample output

Planning the bundled sample data from 2026-11-06 (capacity 6 hrs/day):

```

Planning from 2026-11-06, daily capacity 6.0 hrs/person

Tasks: 12 total, 11 open, 1 done, 53.0 open hours

Load by person:
  Ayesha: 11.0 hrs planned over 5 working day(s), busiest day 3.1 hrs
  Bassam: 31.0 hrs planned over 6 working day(s), busiest day 12.3 hrs
  Omar: 9.0 hrs planned over 6 working day(s), busiest day 2.3 hrs

Flags (3):
  - OVERDUE: T-112 'Prepare handover notes for weekend cover' (Ayesha) was due 2026-11-05.
  - OVERLOADED: Bassam on 2026-11-06 has 12.3 hrs planned (capacity 6.0 hrs).
  - OVERLOADED: Bassam on 2026-11-09 has 6.3 hrs planned (capacity 6.0 hrs).
```

The sample data shows the point of the tool: Bassam is double-booked on
Friday 6 November (an urgent same-day shipment task plus the regular
workload), so that task needs to move or be shared out.

## Files

| File | What it is |
| --- | --- |
| `capacity.py` | The planner (load, spread, flag, report) |
| `test_capacity.py` | 5 tests: weekends, done-task exclusion, flags, sample CSV |
| `data/tasks.csv` | Sample dataset: 12 tasks across 3 people |
| `requirements.txt` | `pandas>=2.0` |
| `output/plan.csv`, `output/report.md` | Generated by running the tool on the sample data |
